# Adding the preliminary test report to your GitHub portfolio

1. Upload `ACCESSIBILITY-TEST-RESULTS.md` to the **root** of your repository.
2. Commit with message `Add preliminary accessibility assessment and verification plan`.
3. Link it from your case study or main README using:

   `[Accessibility assessment and test results](ACCESSIBILITY-TEST-RESULTS.md)`

4. Run the manual checks and replace the `Not tested` entries with actual observations.
5. Do not describe the document as a completed NVDA/axe audit until those tests are performed.

This is a source-review assessment with a test plan, not fabricated test results.
